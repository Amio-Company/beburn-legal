# BeBurn · pagine legali

Privacy, termini d'uso e supporto dell'app BeBurn, in italiano e inglese, pubblicate con GitHub Pages:
https://amio-company.github.io/beburn-legal/

I testi stanno in `src/*.md`: si modificano lì e si rigenerano le pagine con `python3 build.py` (i file `index.html` non si toccano a mano). I segnaposti `[DA COMPLETARE: …]` vanno completati prima di pubblicare. Gli indirizzi sono letti dall'app
(e da App Store Connect): cambiare il percorso di una pagina vuol dire rompere un link già pubblicato.
